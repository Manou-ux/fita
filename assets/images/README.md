# Dossier des images

Placez ici vos images et photographies.

### Exemples d'utilisation :
- `profile.jpg` ou `profile.webp` : Photo de profil pour l'arche de la section héro.
- Formats recommandés : WebP, JPG ou PNG optimisés.
- Dimensions recommandées pour la photo principale : 600x800 px (ratio 3:4).
